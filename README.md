Smart Congestion Detection using YOLOv5 and Vitis AI on ZCU104

OVERVIEW:

This project implements a real-time congestion detection system on the ZCU104 board using YOLOv5 for person detection and Vitis AI DPU acceleration for low-latency edge inference. The system detects and counts people within a defined region of interest and classifies congestion levels as Low, Medium, or High based on crowd density.

KEY FEATURES:

Real-time person detection
DPU-accelerated inference using Vitis AI
Region-based crowd counting
Density-based congestion classification
CPU vs DPU performance evaluation

APPLICATION:


Smart city monitoring, public safety systems, transportation hubs, and crowd management solutions.
